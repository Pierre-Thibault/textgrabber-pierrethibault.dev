Today, 2025-06-30, I begin the release history. There were two releases before, but the history begins today.

2025-06-30: 1.0.6: First version submitted to the Gnome Extensions website.

2025-10-08: 1.1.0: Fixing three issues that has led from the rejection from the Gnome Extensions website:

    - Buymeacoffee is now a user handle
    - Using St.Clipboard API instead of command line utilities
	- Mentioning that the extension access the clipboard in the description

2025-12-15: 1.2.0: Important update for Gnome 49. No longer using Gnome-Screenshot. Small fix.

2026-05-08: 1.2.1: Updated extension for Gnome 50 (contributed by Oharagyk).

2026-10-10: 1.3.0: Added support for Gnome 51.
	- Gnome 50+: area selection uses Clutter gestures (touch screen support) and key controllers
	- Keep the clipboard unchanged when no text is found
	- Ignore the shortcut while a selection is already in progress
	- Remove the selection overlay when the extension is disabled during a selection
	- Keep the same shortcut options after changing the shortcut
	- Close temporary file streams
	- German translation (contributed by uwe-ss)
